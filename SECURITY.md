# Security and responsible disclosure

Do not open a public issue containing credentials, private trajectory data, personal information, unpublished holdout answers, or a reproducible bypass against a deployed control plane.

Until a dedicated disclosure address is published, contact the repository owner through the private contact method listed on her GitHub profile and include only the minimum information required to establish the issue.

## Research-data boundary

Public artifacts must use synthetic, redacted, or explicitly consented trajectories. Production secrets, client information, private communications, raw authentication state, and private social-media identifiers are outside the public dataset.
